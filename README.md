# لوحة تحكم طالب علم — دليل الرفع على Vercel

## 1) قبل أي حاجة: شغّل ملفات SQL في Supabase بالترتيب
في `SQL Editor`، شغّل الملفات دي بالترتيب ده (تخطّى أي ملف سبق وشغّلته):
1. `supabase_setup.sql`
2. `supabase_forum.sql`
3. `supabase_admin.sql`
4. `supabase_moderation.sql`
5. `supabase_features.sql`
6. `supabase_dashboard_v2.sql`
7. **`supabase_dashboard_v3.sql`** (جديد — سجل النشاط، صلاحيات المشرف، الكلمات الممنوعة، الجدولة، الإعدادات العامة)

### ملف v2 الجديد بيعمل إيه بالظبط:
- بيضيف عمود `email` لجدول `profiles` (لإرسال روابط تغيير كلمة المرور من اللوحة)، وبيعبّي الإيميلات للحسابات الموجودة
- بيضيف `target_system` و `target_grade` لجدول `announcements` (استهداف الرسالة العامة)
- بيضيف فهارس (indexes) تسرّع الفلترة والبحث

### ملف v3 الجديد بيعمل إيه بالظبط:
- بيضيف صلاحية "مشرف" (moderator) بجانب "أدمن كامل" — المشرف يقدر يدير المنتدى
  والبلاغات ويشوف الحسابات بس، والأدمن الكامل بس يقدر يدير الحسابات والإعدادات العامة
- بيضيف جدول `admin_audit_log` (سجل نشاط كل الإجراءات الإدارية)
- بيضيف `starts_at`/`ends_at` للرسائل العامة (جدولة تلقائية — تحتاج تفعيل pg_cron، تفاصيل تحت)
- بيضيف جدول `app_settings` (إعدادات عامة يقرأها التطبيق — راجع مستند مواصفات التطبيق الجزء الثاني)
- بيضيف جدول `banned_words` وفلتر تلقائي يمنع نشر أي سؤال/رد فيه كلمة ممنوعة

### تفعيل الجدولة التلقائية للرسائل (اختياري)
لو عايز الرسائل المجدولة (`starts_at`/`ends_at`) تتفعّل/تتخفي أوتوماتيك بدون ما تدخل
تشيلها يدوي: `Supabase Dashboard → Database → Extensions → ابحث عن pg_cron → Enable`،
وبعدين أعد تشغيل `supabase_dashboard_v3.sql`. لو مش عايز الخطوة دي، كل حاجة تانية في
الملف هتشتغل عادي، والرسائل هتفضل شغالة زي ما هي لحد ما تشيلها من اللوحة بنفسك.

## نشر خاصية "الحذف النهائي للحساب" (Edge Function)
صفحة الحسابات فيها زرار "حذف نهائي" بيحتاج Edge Function منشورة على مشروعك (الكود
جاهز في `supabase/functions/admin-delete-user/`):
```bash
# لو أول مرة تستخدم الـ CLI
npm install -g supabase
supabase login
supabase link --project-ref <project-ref-بتاعك>

# نشر الدالة
supabase functions deploy admin-delete-user
```
مفتاح `service_role` بيتحقن تلقائيًا من Supabase جوه بيئة الدالة، مش محتاج تضيفه
بنفسك ولا تحطه في أي كود موقع. لو مش عايز الخاصية دي دلوقتي، خليك مستخدم "حظر
الحساب" العادي — باقي اللوحة هتشتغل عادي بدون ما تنشر الدالة دي.

## 2) خلّي حسابك أدمن (لو أول مرة)
في آخر سطر من `supabase_admin.sql`:
```sql
update public.profiles set role = 'admin' where id = (select id from auth.users where email = 'ضع_إيميلك_هنا@example.com');
```
انسخه لوحده في SQL Editor، غيّر الإيميل بإيميلك، وشغّله. (لازم يكون عندك بروفايل موجود بالفعل).

بعد كده تقدر ترقّي أي حساب تاني لأدمن مباشرة من صفحة "الحسابات" في اللوحة نفسها.

## 3) جرّب لوحة التحكم محليًا
```bash
cd admin_dashboard
npm install
npm run dev
```

## 4) ارفعها على GitHub وانشرها على Vercel
```bash
cd admin_dashboard
git init
git add .
git commit -m "لوحة تحكم طالب علم v2"
git remote add origin https://github.com/USERNAME/taleb-elm-admin.git
git branch -M main
git push -u origin main
```
بعدين على **vercel.com**: Add New → Project → اختار الـ repo → Deploy (هيكتشف مشروع Vite تلقائيًا).

## آخر تحديث — إعادة تصميم كاملة + تحكمات جديدة

### الشكل الجديد
هوية بصرية جديدة كاملة ("دفتر/سجل أكاديمي"): خلفية بارشمنت دافئة، سايدبار كحلي غامق مع لمسة ذهبية، خط عرض El Messiri للعناوين وخط Cairo للنصوص، وعنصر مميز هو "الختم الإداري" (badge بشكل ختم) بيستخدم لحالات زي أدمن/محظور/بلاغ. تصميم متجاوب بالكامل (موبايل وديسكتوب) مع قائمة جانبية قابلة للطي على الموبايل، وتنبيهات (toast) ونوافذ تأكيد عصرية بدل alert/confirm الافتراضية في المتصفح.

### التحكمات الجديدة
- **ترقية/تنزيل أدمن**: زرار مباشر في صفحة الحسابات، من غير ما تحتاج SQL يدوي
- **رابط تغيير كلمة مرور**: تقدر تبعت رابط إعادة تعيين كلمة المرور لأي طالب من صفحة الحسابات (محتاج يكون عنده إيميل مسجل — الحسابات القديمة قبل ملف v2 هتتعبّى تلقائيًا)
- **فلاتر وبحث** في الحسابات (بالاسم/الإيميل، الصف، الحالة) والمنتدى (بحث نصي)
- **لوحة التصنيف**: صفحة جديدة تعرض جدول `user_stats` (ساعات مذاكرة، استمرارية، إنجازات) مع ترتيب حسب أي عمود
- **البلاغات بقت لها دورة حياة**: تبويب "معلّقة" و"تمت المراجعة" بدل الحذف الفوري، مع إمكانية إرجاع بلاغ من المراجَعة للمعلّقة أو حذفه نهائيًا من السجل
- **رسالة عامة متعددة ومستهدفة**: تقدر تنشر أكتر من رسالة، كل واحدة تستهدف نظام/صف معين أو تكون للكل (⚠️ ملحوظة: التطبيق حاليًا بيعرض آخر رسالة نشطة للجميع بغض النظر عن الاستهداف — البيانات جاهزة، لكن محتاجين تعديل بسيط في كود الفلاتر جوه الـ Flutter app لو عايز الاستهداف يشتغل فعليًا)
- **نظرة عامة محسّنة**: رسم بياني بسيط لتسجيلات آخر ٧ أيام + قائمة "آخر نشاط" (أحدث الأسئلة والبلاغات)

### حاجة واحدة مقصودة إننا محضّرهاش
**حذف حساب نهائيًا** من لوحة التحكم محتاج صلاحيات `service_role` بتاعة Supabase، ومفيش طريقة آمنة تحطها في كود موقع بيشتغل في متصفح المستخدم (أي حد يفتح Developer Tools هيقدر ياخدها ويتحكم في القاعدة بالكامل). البديل الآمن المتاح دلوقتي هو **الحظر** (بيمنع تسجيل الدخول فورًا). لو عايز حذف حقيقي لاحقًا، الطريقة الصح هي Supabase Edge Function منفصلة تستخدم service_role من السيرفر — ممكن نضيفها في خطوة تانية لو حبيت.
